## 📖 Sobre o Projeto

O processo de sustentabilidade envolve entender os impactos dos nossos produtos e resíduos, além das dependências que temos dos recursos naturais. Os altos gastos com equipamentos comprados, por exemplo, podem pesar bastante para produtores rurais e fazendeiros que trabalham com agricultura e criação.

Pensando nisso, este projeto propõe uma **chocadeira automatizada e sustentável**, uma alternativa viável e acessível para ajudar esses produtores.

## 🎯 Objetivos

- Criar, de forma sustentável, uma chocadeira com processo automatizado
- Reduzir os custos para pequenos produtores rurais
- Estimular o aprendizado do grupo com ferramentas de software
- Desenvolver conhecimentos em tecnologia e circuitos eletrônicos
